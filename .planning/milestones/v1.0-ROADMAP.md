## Phase Details

### Phase 1: Fix YouTube Chunk Deletion & Cache Staleness
**Goal**: YouTube transcript chunks survive page loads and cached study content invalidates when new YouTube sources are added
**Depends on**: Nothing (first phase)
**Requirements**: BKFL-01, BKFL-02, BKFL-03, CACH-01, CACH-02
**Success Criteria** (what must be TRUE):
  1. Backfill logic fetches YouTube URLs from Firestore source records (not just contextFiles) before calling replaceIndexedChunks
  2. replaceIndexedChunks receives YouTube chunks alongside file chunks when backfill triggers
  3. YouTube chunk documents in Firestore still exist after a full page reload
  4. sourceTruthVersion increments after handleAddSourceFromUrl successfully adds a YouTube source
  5. Previously cached study content is regenerated (not served from stale cache) after a YouTube source is added
